# BasTech — Bassey Stephen Portfolio

Production developer portfolio for **Bassey Stephen** (BasTech) — Full-Stack Web Developer and Computer Science student at Akwa Ibom State University.

Live deployment: [bastech.vercel.app](https://bastech.vercel.app)

## Tech Stack & Architecture

- **Framework**: Next.js (App Router) & React
- **Analytics**: `@vercel/analytics`
- **Styling**: Tailored technical editorial design system in native CSS (`styles/globals.css`)
- **Typography**: Inter & JetBrains Mono

## Project Directory

Documented and verified projects in `data/projects.js`:
- **Aberra**: Next.js 16, React 19, TypeScript 5, Prisma, PostgreSQL, NextAuth.
- **NaijaBox**: Next.js 15, React 19, TypeScript 5.7, Drizzle ORM, Neon Serverless PostgreSQL.
- **IHCDT Scholarship Portal**: Next.js 14, React 18, TypeScript 5, Prisma, Vercel Blob, Nodemailer.
- **NACOS Campus Quest**: HTML5, CSS3, JavaScript, PHP event platform.
- **Elevate Agency**: Single-page editorial frontend showcase.
- **Classify**: Digital asset grading workflow concept.
