# Stephen Bassey — Portfolio

Personal portfolio site for Stephen Bassey, Frontend Web Developer. Built with Next.js (App Router).

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view it.

## Structure

- `app/` — pages (App Router): layout, metadata, and the home page
- `components/` — `Nav`, `ProjectsList` (search + tag filtering), `ProjectCard`
- `data/projects.js` — project entries shown on the home page (replace with your real projects)
- `styles/globals.css` — global styles (dark navy + gold theme)

## Customizing

- Update project entries in `data/projects.js`
- Edit bio/skills text directly in `app/page.js`
